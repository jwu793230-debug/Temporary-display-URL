# 智慧建造数字孪生展示中心 · B08

静态三维展厅漫游。入口为 `index.html`，模型、界面程序和演示素材位于 `assets/`。

鼠标拖动转向，W/A/S/D 移动；可切换区域、查看总览、启动导览并点击设备屏幕。手机可使用页面方向按钮。

2026-09-21 轻量化版本：全部运行资源由 63.77 MiB 减至 23.62 MiB，约减少 63%。入口 HTML 约 6.5 KiB，可先显示加载界面与实际下载进度。资源文件名含内容哈希，支持浏览器缓存与更新。

本轮采用无损优化：共享 3,129 个重复二进制数据块；主模型及体验数据使用 gzip 打包，由浏览器解压，附带兼容解压器。保留原模型几何精度、贴图分辨率和编码、材质、灯光与全部交互。不是减面或降低画质版本。

通过 GitHub Pages 或其他静态 HTTP 服务打开。此前单文件离线版保留在本机，历史 Git 提交 `07d4598` 也可恢复原发布版。具体体积与模型数据核对见 `optimization.json`。

首次加载取决于网络速度，需要支持 WebGL 的现代浏览器。展示内容为方案演示，设备尺寸不是厂家施工尺寸。
