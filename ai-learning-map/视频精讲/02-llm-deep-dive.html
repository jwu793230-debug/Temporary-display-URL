第一遍：零基础讲解

第二集：ChatGPT 和 LLM 到底怎样工作

开场：会说话不等于有一座真相图书馆

ChatGPT 这类系统最容易被误解成“装着全世界答案的机器”。更接近的说法是：它读过巨大数量的文字，学会在一段文字后面接什么最像人会写出的下一段。这个看似简单的训练目标，在规模足够大时会长出翻译、写代码、归纳和推理等能力；同时也解释了它为什么会一本正经地说错话。

今天的路线图

我们依次看 token、预训练、Transformer、后训练、检索和工具，以及幻觉为什么不是“偶尔的小毛病”。

一、Token：模型读的不是整句

模型把文字切成 token，可以理解为一小块一小块的积木：有时是一个字，有时是一个词的一部分，有时是标点。它每次估计“下一块积木”最可能是什么。它并非逐个字母地看世界，因此数字符、拼写罕见单词和机械计数常会出错。

二、预训练：海量完形填空

训练时，系统读到“今天天气很”，目标可能是“好”；读到一段代码，目标可能是下一个符号。预测错了就微调内部数值，预测对了就保留方向。反复进行后，模型把语言、事实片段、写作结构和代码规律压缩进大量参数中。它像读过无数书的人，却不能保证记得每一本书的页码，也分不清训练材料里所有真假。

三、Transformer：为什么它能看上下文

Transformer 的关键是注意力机制。可以把它想成读一句长话时，一边读到“它”，一边回头判断“它”指的是前面哪个名词；读合同中的金额时，也会注意到前后日期和条件。许多层这样的“看哪里更相关”和“怎样组合信息”叠起来，形成对上下文的表征。但它的工作窗口有限，窗口外的信息不会自动永久记住。

四、后训练：从续写机器变成助手

基础模型只会接着写互联网风格的文字。后训练拿来大量“用户提问—助手回答”的示例，让它习惯听指令、采用有帮助的语气、避免危险回答。之后还可通过偏好比较或强化学习，让更清楚、更安全、更正确的回答被奖励。这里要注意：礼貌、条理和安全边界变好了，不代表所有事实都变正确。

五、RAG、工具和幻觉

当问题依赖最新资料，可靠方法不是逼模型“回忆”，而是先检索权威文件，再让它只根据检索结果回答，这叫检索增强生成。计算交给计算器，查库存交给数据库，执行程序交给受限工具。幻觉则是模型在信息不足时仍然努力把一句话续写完整；它听起来合理，恰恰更危险。因此要问来源、区分已知与猜测，并核对关键结论。

场景：问药和修代码

问健康问题时，模型可以把化验单术语翻成白话，帮你准备就诊问题，却不能替代医生诊断。修代码时，它能解释报错、给出候选补丁；真正的裁判是测试是否通过、程序是否在真实数据上正确运行。

最常见的误区

不要把模型的“记忆”当数据库；不要把长推理当证明；不要把拒答或自信当能力大小的精确刻度。它是一种强大的语言和模式工具，可靠性要由资料、测试、权限和人共同补齐。

复盘

LLM 的底层动作是预测下一个 token；Transformer 让预测能利用上下文；后训练把续写器塑造成助手；检索和工具把它接回现实；核验是使用链条不可省略的一环。

一句话：ChatGPT 是“预训练的下一个 token 预测器”经对话微调、强化学习、工具与检索包装后形成的产品；理解各层，才能理解其能力和失误。

讲稿式详细提纲

  1. 预训练：收集网页、书籍、代码等文本，清洗、去重、tokenize；模型在海量“前缀 → 下一个 token”样本上最小化预测误差。
  2. Transformer：token 先变为向量，位置编码加入顺序；多层自注意力让当前位置按相关性读取上下文，MLP 做非线性变换；训练用反向传播更新参数。
  3. 基础模型：它模仿互联网文本分布，因此本来是“文本续写器”，会扮演不同文体、复述错误信息，也可能在不确定时继续编造。
  4. 后训练（SFT）：把高质量的“用户—助手”对话写成同一 token 序列继续训练，令模型习得助手格式、指令遵循与拒答边界。
  5. 偏好/RL：针对可验证题或人类偏好，比较候选回答、优化能获得高奖励的轨迹；推理模型特别依赖让它生成更长的可检查推导与工具调用。
  6. 可靠性补丁：不确定性训练、系统提示、RAG、函数调用与外部验证分别处理不同缺陷；它们不是让模型“天然知道真相”。
  7. 结论：LLM 有“参差不齐”的能力面——可写很强的代码却数错字符。用它时把高风险点变成可测试、可检索、可复核的环节。
