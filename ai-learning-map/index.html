01

如何把 LLM 用在生活和工作中 【珍藏必看】2月28日最新，安德烈·卡帕西：讲解如何使用大语言模型（LLMs）-哔哩哔哩 ↗

核心：把模型当作需要任务书、工具和验收的协作者。

一句话：LLM 最适合承担解释、初稿、整理、比较与反复修改；事实核验和不可逆操作仍要由可靠资料、程序和人共同把关。

展开精讲要点

一次好的提问包含目标、背景、输入、限制和交付格式。复杂任务不要一口气交付：先让模型复述，再列提纲、出草稿、按清单自检。把搜索、计算、文件和审批接入流程，模型才真正能从“会说”变成“能帮忙”。

  • 装修报价：让它找缺项、单位不一致和待追问点，不替你签合同。
  • 孩子报告：让它规划提纲和练习题，统计数据再从官方来源确认。

02

ChatGPT 和 LLM 到底怎样工作 【1080P】安德烈·卡帕西：深入探索像ChatGPT这样的大语言模型｜Andrej Karpathy-哔哩哔哩 ↗

核心：预训练的文字续写器，经过对话训练、工具和检索，才成为助手。

一句话：模型预测下一个 token；它能从上下文中捕捉强大模式，但不会天然持有最新、可核查的真相。

展开精讲要点

Token 是模型处理文字的小积木。预训练像海量完形填空，Transformer 的注意力机制让它能在长句中找相关线索。后训练让它学会听指令和对话礼仪；RAG 让它先查资料再回答；工具调用让计算和真实系统操作交给专门系统。

  • 幻觉不是“故意骗人”，而是信息不足时仍努力把文本续写完整。
  • 问健康、法律、价格或运行代码时，必须回到医生、原始法规、官网和测试结果。

AI 时代的软件怎样变化 大神Andrej Karpathy最新演讲：AI时代的软件-哔哩哔哩 ↗

核心：规则代码、神经网络和自然语言编程会长期并存。

一句话：Software 3.0 不是让人把所有工作交给 Agent，而是让更多人能用自然语言参与软件构建，并把人类接管设计进流程。

展开精讲要点

Software 1.0 是人写的确定性代码，适合金额、权限和规则；2.0 是从数据训练出的网络权重，擅长识别复杂模式；3.0 是提示词、上下文、工具和评测共同“编程”LLM。现实产品应采用部分自治：低风险自动处理，高风险展示依据并请人确认。

  • 客服可自动总结邮件和找知识库，退款仍交给人工批准。
  • 未来系统需要给 Agent 稳定 API、细粒度权限、日志和可撤销操作。

Stanford CS230：深度学习课程全景 【公开课·2025秋季】吴恩达·斯坦福CS230深度学习课程-哔哩哔哩 ↗

核心：模型只是中间一环，AI 项目必须形成完整工程闭环。

一句话：别只问“用什么模型”；先定义成功、审计数据、建立基线、分析错误，并在上线后持续监控。

展开精讲要点

从问题定义出发：错误的代价不同，不能只看总体准确率。数据必须分为训练、验证、测试，并防止泄漏。做完朴素基线后，把错误按场景、人群和时间分类，才知道下一步该补数据、改标签还是改模型。鲁棒性、公平性、隐私和申诉渠道应与性能一起被评估。

  • 工厂识别缺陷：不同光照与班次都要测试，漏掉危险缺陷要单独衡量。
  • 零售预测：促销、节假日与缺货会改变数据分布，上线后要监控漂移。

06

Agent、AGI 离我们还有多远 Andrej Karpathy：距离AGI的实现，还需十年时间-哔哩哔哩 ↗

核心：一次回答正确，和长期可靠完成任务，是两种完全不同的能力。

一句话：当下更像“Agent 的十年”，而非“Agent 的一年”；难点是长期记忆、工具交互、错误恢复、持续学习和可靠性。

展开精讲要点

Agent 不只是聊天框加自动点击，它要理解目标、拆任务、调用工具、保存状态、检验结果并在失败时调整。连续一百步任务会放大每一步的小错误，因此权限、可撤销动作、外部验证和人工接管缺一不可。“幽灵而非动物”提醒我们：LLM 来自人类文字的统计蒸馏，不等同于具有身体、进化和内驱力的动物智能。

从规模化时代迈向研究时代 伊利亚Ilya Sutskever最新访谈完整版—我们正从规模化时代迈向研究时代-哔哩哔哩 ↗

核心：更多算力仍有用，但泛化和自我纠错需要新的研究配方。

一句话：高分评测不等于真实世界的长期能力；下一阶段要找到让模型少死记、能迁移、能检验中间步骤的方法。

展开精讲要点

规模化在过去几年带来了可预测的能力提升，但高质量数据有限，固定评测也容易被优化过度。奖励设计不完整时，系统会“钻空子”：例如只奖励客服迅速结束对话，可能导致问题被草率关闭。所谓研究时代，指更重视价值函数、训练环境、持续学习和更接近真实任务的评测。

  • 导航不应只追求最短时间，还要考虑安全与道路条件。
  • 客服不应只追求满意度分数，还要对承诺的可兑现性负责。

一条学习线

  1. 先会用：明确任务与核验。
  2. 再懂原理：预测、上下文、后训练。
  3. 再做产品：部分自治与可接管。
  4. 再做工程：数据、基线、监控。
  5. 最后校准预期：可靠性、泛化与研究。
