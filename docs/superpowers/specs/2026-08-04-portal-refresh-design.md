# Temporary Display 门户精简改版设计

## 目标

将现有门户从“按单个场景罗列页面”调整为“按成果类型组织入口”，压缩首屏介绍区，突出方案类与大屏类两条浏览路径，并移除半马训练 PWA。

## 页面结构

### 顶部导航

保留现有品牌标识、`Temporary Display` 名称、中文副标题和 GitHub Repository 链接，不改变整体深色工业科技风格。

### 精简首屏

- 首屏高度约为现有首屏的一半，保留左侧介绍、右侧统计的基本结构。
- 主标题改为“智能建造成果展示门户”。
- 简介改为“集中呈现智能建造解决方案、可视化大屏与工程三维成果，便于方案汇报、项目演示和成果预览。”
- 仅保留两个主操作：
  - “查看解决方案”，跳转到方案类分栏。
  - “浏览可视化大屏”，跳转到大屏类分栏。
- 统计统一使用成果类型维度：
  - 8 项展示成果
  - 2 项方案类成果
  - 6 项大屏与三维展示

### 成果分栏

桌面端采用左窄右宽的两栏布局，左侧约 35%，右侧约 65%；移动端依次纵向排列。

左侧“解决方案”包含：

1. 抽水蓄能电站智能建造整体解决方案
2. 道路项目智能化施工管理系统方案

右侧“可视化大屏”包含：

1. 道路智慧管理系统大屏
2. 抽水蓄能智能管理平台
3. 抽水蓄能三维数字孪生驾驶舱
4. 澳门盾构机实时监测中心
5. 大坝船闸 3D 模型 GLB 资产版
6. 大坝船闸 3D 模型

卡片继续使用现有深色面板风格，但强化类别内的统一性、标题层级与入口按钮。所有卡片保持整卡可点击，并提供清晰的悬停与键盘焦点状态。

## 排除项

- 门户不再展示半马训练 PWA。
- 本次工程成果门户不展示 AI 视频精讲学习地图及其子页面。
- 不删除被排除页面的源文件，仅移除门户入口。

## 响应式与验证

- 桌面端验证 1920×1080 和 1366×768，首屏应明显变薄，内容无裁切或横向滚动。
- 移动端验证 390×844，两栏改为纵向排列，按钮和卡片可正常操作。
- 自动检查 8 个成果入口、两个分类锚点、三项统计文案，以及半马和 AI 学习入口均未出现在门户中。
- 浏览器检查所有入口地址、悬停/焦点状态、首屏文案和分类顺序。
